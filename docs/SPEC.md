# 周转托盘回空回收业务规格

## 输入与时点

`day` 从演练档案起始日计数，`arrived` 表示入账日，`clock` 以 15 分钟为一格。测量在发生日之后一日内到达才可进入时点样本，超过窗口的补录留在隔离证据。跨日结果通过 `available` 回读，训练使用冻结日前已确认的最后一份回执。

业务组包括县域专线、同城循环、干线中转、门店联配。同一 `case_id` 的同版本异值记录整笔隔离，重复记录只计一笔。

| 信号源 | 含义 | 接受范围 |
| --- | --- | --- |
| `age` | 已在途天数 | 0 至 24 |
| `loops` | 近月流转次数 | 1 至 20 |
| `distance` | 往返里程 km | 3 至 190 |
| `collectors` | 可到仓提货班组 | 0 至 6 |
| `pallets` | 同运单托盘数 | 1 至 25 |
| `deposit` | 单托押金 元 | 15 至 85 |
| `disputed` | 押金争议 | 0 至 1 |

## 计算与裁决

使用分层 Kaplan–Meier，目标单位为 天。数据冻结以 `as_of` 为锚点，选择截至第 `as_of-64` 日的历史，随后依次保留校准段、回放段和待裁决段。
训练样本的中位数与 MAD 用于共享缩放。组内样本数足够时，用组内中位数补齐非关键测量。以下特征按同一名次供回放和推理。

| 派生特征 | 计算 |
| --- | --- |
| `elapsed` | `age` |
| `turnover` | `loops / 20` |
| `lane_distance` | `distance / 190` |
| `load_units` | `pallets / 25` |

关键测量不全、回放门限失败或组分布出现明显变化时进入人工复核。业务锁包括押金争议锁或无提货班组。最终分派受同链路回收班组总额和组内上限约束，使用额度守恒回读工作单。

## 两天回空判定

回放和派单都以托盘当时已在途的天数（`age`）为起点，估计再过一个固定窗口仍未归还的概率 `P(T > age+2 | T > age)`。总时长取 `age` 加回执给出的时长，右删失回执在观察结束处退出在险集合。

- 在途回执（`occurred` 为假）只证明观察结束时还没归还：观察时长已满两天才算「窗口内没回」，不足两天无法判明，留在隔离证据。
- 快照日已确认归还（`occurred` 为真，确认日不晚于快照日）的托盘直接撤出候选，不占车位、不计入逐单证据；晚于快照日才确认的归还记录不改动当班重算结果。
- 本线路可判明这两天内回没回的历史单不少于二十笔时用本线路，否则借全场记录，全场也不足则转人工（`HORIZON_UNSUPPORTED`），不占车位。
- 概率严格过半才可派单；未过半的记录为 `WITHIN_HORIZON` 只观察。阈值比较用精确有理数，显示舍入不能改变派单资格。
